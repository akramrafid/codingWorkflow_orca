# Orca Project Scaffold Template

This template defines the standard directory structure and initialization procedure for projects generated by the Orca Agent Operating System.

---

## Output Directory Convention

All Orca-generated projects are created in:
```
D:\OrcaProjects\<project-name>\
```

The `<project-name>` is derived from the user's brief:
- Lowercased
- Spaces replaced with hyphens
- Special characters removed
- Maximum 40 characters

Examples:
- "Build a SaaS project management tool" → `saas-project-manager`
- "Build a RAG customer support assistant" → `rag-support-assistant`
- "Build an e-commerce platform for handmade goods" → `ecommerce-handmade`

## Initialization Commands

### Next.js (SSR/SSG Web App)
```powershell
$projectDir = "D:\OrcaProjects\<project-name>"
New-Item -ItemType Directory -Force -Path $projectDir
cd $projectDir
npx -y create-next-app@latest ./ --typescript --eslint --src-dir --app --import-alias "@/*" --use-npm
npm install
git init
git add -A
git commit -m "chore: initial project scaffold via Orca"
```

### Vite + React (SPA)
```powershell
$projectDir = "D:\OrcaProjects\<project-name>"
New-Item -ItemType Directory -Force -Path $projectDir
cd $projectDir
npx -y create-vite@latest ./ --template react-ts
npm install
git init
git add -A
git commit -m "chore: initial project scaffold via Orca"
```

### Python FastAPI (API Backend)
```powershell
$projectDir = "D:\OrcaProjects\<project-name>"
New-Item -ItemType Directory -Force -Path $projectDir
cd $projectDir
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install fastapi uvicorn sqlalchemy alembic pydantic python-dotenv
pip freeze > requirements.txt
git init
git add -A
git commit -m "chore: initial project scaffold via Orca"
```

### Node.js Express (API Backend)
```powershell
$projectDir = "D:\OrcaProjects\<project-name>"
New-Item -ItemType Directory -Force -Path $projectDir
cd $projectDir
npm init -y
npm install express cors helmet dotenv
npm install -D typescript @types/express @types/node tsx vitest
npx tsc --init
git init
git add -A
git commit -m "chore: initial project scaffold via Orca"
```
