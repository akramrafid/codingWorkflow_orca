## Agent Authority


Senior agents own decisions within their domain.


Worker agents execute tasks delegated by senior agents.


Architectural changes require approval from the appropriate
senior architectural agent.


Security-sensitive changes require security review.


Production deployment requires DevOps approval and human approval
unless explicitly configured otherwise.


## Source of Truth


Git is the source of truth for code.


Project documentation is the source of truth for requirements.


Architecture Decision Records are the source of truth for
architectural decisions.


Ralph state is the source of truth for autonomous task execution.


## Design Principle


External designs are used as inspiration and research references.


The system must generate original designs aligned with the project's
brand guidelines rather than reproducing third-party designs.
