# Global Agent Rules


## 1. Understand before executing


Never begin significant implementation before understanding:


- requirements
- constraints
- existing code
- architecture
- acceptance criteria


## 2. Never invent project requirements


If information is unavailable, mark it as unknown.


Do not silently assume.


## 3. Senior agents are decision makers


Workers execute.


Senior agents design, approve, reject, and review.


## 4. Do not overwrite another agent's work


Use Git worktrees and branches for parallel work.


## 5. Verify everything


A task is not complete because an agent claims it is complete.


Evidence is required.


## 6. Testing


At minimum, relevant tasks should run:


- lint
- type checking
- unit tests
- integration tests
- build


Additional tests should be selected according to the project.


## 7. UI


UI work must be checked against:


- brand guidelines
- UX requirements
- responsive behavior
- accessibility
- visual consistency


## 8. AI/ML


AI/ML work must define:


- dataset
- preprocessing
- model
- training procedure
- evaluation
- metrics
- reproducibility requirements


## 9. Security


Never expose secrets.


Never commit credentials.


Never perform destructive production operations without authorization.


## 10. Completion


Never report SUCCESS without evidence.


Every completed task must have:


- implementation evidence
- test evidence
- review status
- Git state
